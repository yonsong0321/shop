# PRD: 물풍선 1인 생존 게임 (크레이지 아케이드 스타일)

| 항목 | 내용 |
|---|---|
| 문서 버전 | v1.0 |
| 작성일 | 2026-11-14 |
| 상태 | 초안 |

---

## 1. 개요

플레이어가 격자 맵에서 물풍선을 설치해 폭발을 피하며 120초 동안 살아남는 1인용 아케이드 게임이다. 브라우저에서 HTML5 Canvas와 순수 JavaScript로 구현하며, HTML 파일을 열면 바로 실행된다.

## 2. 목표와 범위

**목표**
- 방향키와 스페이스바만으로 즉시 이해되는 조작 제공
- 이동 → 물풍선 설치 → 폭발 → 생존으로 이어지는 핵심 루프 구현
- 설치 없이 열리는 단일 HTML 파일 산출

**범위 밖 (MVP 제외)**
- 적(몬스터), 아이템(폭발 범위·개수 증가 등), 점수 시스템
- 멀티플레이, 맵 선택, 다수 스테이지
- 사운드, 모바일 터치 조작, 기록 저장/랭킹

## 3. 기술 스택

- HTML5 Canvas + Vanilla JavaScript (외부 라이브러리 없음)
- 산출물: `prj4/index.html` 단일 파일 (CSS 포함 가능)
- 대상 브라우저: 최신 Chrome, Edge, Firefox

## 4. 사용자 시나리오

1. 사용자가 페이지를 연다 → 시작 화면이 표시된다.
2. Space를 누르면 게임이 시작되고 120초 타이머가 흐른다.
3. 방향키로 이동하고 Space로 물풍선을 설치한다.
4. 물풍선은 3초 뒤 폭발해 벽과 블록을 부수고, 범위 안의 플레이어는 사망한다.
5. 120초를 버티면 "생존 성공", 사망하면 "게임 오버"가 표시되고 Enter 또는 Space로 재시작한다.

## 5. 기능 요구사항

### FR-1 이동
- **FR-1.1** ←↑↓→ 키로 상하좌우 4방향 이동한다.
- **FR-1.2** 키를 누르고 있으면 연속 이동한다.
- **FR-1.3** 이동은 고정 벽, 부숴지는 블록, 물풍선에 막힌다.
- **FR-1.4** 방금 설치한 물풍선 칸에서는 그 칸을 벗어날 때까지 통과할 수 있다. 벗어난 뒤에는 그 칸이 벽처럼 막힌다.

### FR-2 물풍선 설치
- **FR-2.1** Space를 누르면 플레이어가 서 있는 칸에 물풍선을 설치한다.
- **FR-2.2** 이미 물풍선이 있는 칸에는 설치할 수 없다.
- **FR-2.3** 동시에 존재할 수 있는 물풍선은 1개다. 폭발 후 다시 설치할 수 있다.
- **FR-2.4** 설치 후 3초가 지나면 자동으로 폭발한다.

### FR-3 폭발
- **FR-3.1** 폭발은 중심 칸과 상하좌우 각 1칸, 최대 5칸에 적용된다.
- **FR-3.2** 고정 벽은 파괴되지 않으며, 그 방향으로의 폭발 전파를 막는다.
- **FR-3.3** 부숴지는 블록은 폭발로 제거되며, 그 칸에서 해당 방향의 전파가 멈춘다.
- **FR-3.4** 폭발 범위 안에 있는 다른 물풍선은 즉시 연쇄 폭발한다.
- **FR-3.5** 폭발 이펙트는 0.5초간 표시된 뒤 사라진다.
- **FR-3.6** 폭발 범위에 플레이어가 포함되면 즉시 사망하고 게임 오버가 된다.

### FR-4 맵
- **FR-4.1** 맵은 13열 × 11행 격자이며, 타일 크기는 48px(캔버스 624 × 528px)이다.
- **FR-4.2** 테두리와, 0부터 센 열·행 인덱스가 모두 짝수인 내부 칸은 고정 벽이다.
- **FR-4.3** 나머지 빈 칸 중 약 65%에 부숴지는 블록을 무작위로 배치한다. 게임마다 새로 생성한다.
- **FR-4.4** 플레이어 시작 칸(좌상단, 열 1·행 1)과 그 오른쪽·아래쪽 칸에는 블록을 배치하지 않는다.
- **FR-4.5** 맵은 1종만 존재한다.

**예시 맵** (`P` 시작 위치, `#` 고정 벽, `B` 부숴지는 블록, `.` 빈 칸)

```
#############
#P.B.B.B.B.B#
#.#B#.#B#.#B#
#.B..B.B..B.#
#B#.#B#.#B#.#
#..B..B..B..#
#.#B#B#.#B#.#
#.B.B..B.B..#
#.#B#.#B#.#B#
#.B..B..B.B.#
#############
```

### FR-5 게임 상태
- **FR-5.1** 시작 상태: 제목과 "Space를 눌러 시작" 안내를 표시한다.
- **FR-5.2** 플레이 상태: 120초 타이머가 흐르고 조작이 가능하다.
- **FR-5.3** 클리어: 120초를 생존하면 "생존 성공" 화면을 표시한다.
- **FR-5.4** 게임 오버: 폭발에 맞으면 "게임 오버" 화면을 표시한다.
- **FR-5.5** 재시작: 결과 화면에서 Enter 또는 Space를 누르면 새 맵과 120초 타이머로 초기화된다.

### FR-6 HUD
- **FR-6.1** 화면 상단에 남은 시간을 표시한다 (예: `01:45`).

## 6. 조작법

| 키 | 동작 |
|---|---|
| ← ↑ ↓ → | 이동 |
| Space | 물풍선 설치 (시작·재시작 키 겸용) |
| Enter | 재시작 (결과 화면에서) |

## 7. 게임 수치 요약

| 항목 | 값 | 비고 |
|---|---|---|
| 맵 크기 | 13 × 11 타일 | 타일 48px |
| 플레이어 이동 속도 | 약 3타일/초 | 튜닝 가능 |
| 물풍선 동시 설치 | 1개 | 가정 (11절 참고) |
| 물풍선 폭발 시간 | 3초 | |
| 폭발 범위 | 중심 + 상하좌우 1칸 | 고정 |
| 폭발 이펙트 지속 | 0.5초 | |
| 부숴지는 블록 밀도 | 빈 칸의 약 65% | 튜닝 가능 |
| 생존 목표 시간 | 120초 | 클리어 조건 |

## 8. 비기능 요구사항

- **NFR-1 실행성**: 서버 설치 없이 HTML 파일을 브라우저로 열면 실행된다.
- **NFR-2 성능**: `requestAnimationFrame` 기반 루프로 60 FPS를 목표로 한다.
- **NFR-3 입력 반응**: 키 입력 후 체감 지연이 없어야 한다 (목표 100ms 이내).
- **NFR-4 의존성**: 외부 라이브러리, 이미지, 사운드 파일 없이 도형과 색으로 표현한다.
- **NFR-5 호환성**: 최신 Chrome, Edge, Firefox에서 동작한다.

## 9. 인수 조건

- [ ] **AC-1** ←↑↓→ 키로 상하좌우 이동하며, 벽·블록·물풍선에 막힌다.
- [ ] **AC-2** Space를 누르면 현재 칸에 물풍선이 설치되고 3초 뒤 폭발한다.
- [ ] **AC-3** 폭발은 상하좌우 1칸에 적용되며, 고정 벽 너머로 전파되지 않는다.
- [ ] **AC-4** 부숴지는 블록은 폭발로 사라지고, 그 블록 너머로는 폭발이 전파되지 않는다.
- [ ] **AC-5** 폭발 범위에 플레이어가 있으면 게임 오버 화면이 표시된다.
- [ ] **AC-6** 120초를 버티면 "생존 성공" 화면이 표시된다.
- [ ] **AC-7** 생성된 맵에서 플레이어 시작 칸과 그 오른쪽·아래쪽 칸에는 블록이 없다.
- [ ] **AC-8** 재시작하면 새 맵이 생성되고 타이머가 120초로 초기화된다.
- [ ] **AC-9** 물풍선이 동시에 2개 이상 존재하지 않는다.
- [ ] **AC-10** 폭발 범위 안의 다른 물풍선이 연쇄 폭발한다.

## 10. 화면 구성

- **시작 화면**: 게임 제목, "Space를 눌러 시작" 안내
- **게임 화면**: 중앙에 맵, 상단에 남은 시간
- **결과 화면**: "생존 성공" 또는 "게임 오버", "Enter/Space로 다시 시작" 안내

## 11. 가정 및 확인 필요 사항

| 항목 | 현재 가정 | 변경 시 영향 |
|---|---|---|
| 물풍선 동시 설치 개수 | 1개 | 2개 이상이면 난이도가 낮아짐 |
| 연쇄 폭발 | 있음 | 없애면 AC-10 삭제 |
| 풍선 위 통과 규칙 | 설치 직후 그 칸을 벗어날 때까지만 통과 가능 | 항상 막히게 하면 FR-1.4 삭제 |
| 시작 화면 | 별도 시작 화면 있음 | 바로 시작하면 FR-5.1 삭제 |
| 점수 | 없음, 남은 시간만 표시 | 점수를 넣으면 FR-6 확장 필요 |
| 이동 속도·폭발 시간 | 3타일/초, 3초 | 플레이테스트 후 조정 |
